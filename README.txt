# Configuración Básica de aplicación vulnerable
# En primer lugar prepararemos un ambiente virtual
▪ Paso 1: Crear la carpeta del proyecto y entrar en ella
  mkdir lab_web && cd lab_web

▪ Paso 2: Crear el entorno virtual
  python -m venv venv

▪ Paso 3: Activar ambiente virtual
  source venv/bin/activate

▪ Paso 4: Instalar dependencias necesarias
  pip install flask

▪ Paso 5: Una vez creados los archivos init_db.py y app.py, ejecutar:
  ✓ python init_db.py
  ✓ python app.py
